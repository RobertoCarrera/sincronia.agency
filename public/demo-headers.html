Cmd+K command palette

Header normal + botón "Buscar ⌘K" antes del CTA. Pulsa el shortcut (o click) y se abre un command palette tipo Linear/Vercel con búsqueda fuzzy. Tech-vibe, demuestra que vives la web moderna.

Lo que hacemos por tu negocio

El header flotante con border-radius da sensación "premium app". El marquee de servicios añade motion continuo y comunica de un vistazo todo lo que haces.

Clave: el dock con border-radius:9999px y sombra fuerte es el patrón que usa Linear, Vercel, Arc. El marquee duplica el contenido para hacer loop infinito sin corte visible.
D

Mix A + B (NAP + Cmd+K)

Lo mejor de los dos mundos: top bar con NAP + status pill, y el command palette integrado en el main bar. Más denso en info y funcionalidad. Para una agencia que quiere transmitir todo a la vez.
